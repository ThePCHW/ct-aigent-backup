# ct-aigent-backup

ct-aigent-backup is a private, internal backup tool. It is not offered to the public.

It runs on our own server and uses rclone to upload encrypted backup files to the owner's own Google Drive account. It only requests the Google Drive scope drive.file, so it can only see and manage files that it created itself. It cannot read any other files in Google Drive.
