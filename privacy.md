# Privacy Policy - ct-aigent-backup

Last updated: 30 October 2026

ct-aigent-backup is a private, internal backup tool used only by its owner. It is not offered to the public.

What it accesses: the tool requests only the Google Drive scope drive.file. With this scope it can only create, see and manage files that it uploaded itself. It cannot see or read any other files in the user's Google Drive.

What it stores: encrypted backup files of our own internal systems, uploaded to the owner's own Google Drive. The files are encrypted before upload.

Sharing: we do not sell, share or transfer Google user data to any third party. Google user data is not used for advertising or for training AI models.

Retention and deletion: backup files are kept for a limited time and then deleted automatically. You can remove the tool's access at any time at https://myaccount.google.com/permissions

Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.
